## Installation ##

 * Clone das Repository
 
git clone https://bitbucket.org/dhdigilab/dsb-text-mining/

 * Verschiebe den Ordner in den www-Ordner

cd [www-Ordner]/dsb-text-mining

python3 setup.py dsb


 * Das Digilab sollte jetzt unter [host]/dsb-text-mining erreichbar sein.
