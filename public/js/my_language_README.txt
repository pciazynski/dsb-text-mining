Place your translation information in the file my_language.js to override the default translation. 
You can copy the language variables from lib/def_language.js and replace their values as you see fit. 
That file will not be modified by updates but backups outside the .git project are recommended in case it gets accidentally overwritten.
This file is not versioned and your changes cannot be restored via .git if it is (accidentally) overwritten by an update.
