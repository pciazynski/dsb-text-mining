Hier werden gemeinsam auftretende Tokens (hier konkret Bigrams) als Netzwerk sowie Liste dargestellt. LogDice (Pavel Rychlý (2008): A Lexicographer-Friendly Association Score) berechnet sich als 14 + Log2 { 2 * Häufigkeit Links,Rechts ) / ( HäufigkeitLinks + HäufigkeitRechts ) }.
Ein Klick auf einen Netzwerkknoten oder ein Token in der Liste zeigt unten die linken und rechten Nachbarn dieses Tokens.
